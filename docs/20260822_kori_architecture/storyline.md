# Storyline — KORI Answers 아키텍처

> 2단계. 결론과 그 논리 구조(Pyramid Principle). **사용자 승인 게이트.**

## Governing thought (한 줄 결론)
> KORI Answers는 보안·정합성·응답 품질을 사람의 운영이 아니라 **아키텍처
> 구조로 보장**한다 — 결정론적 보안 레이어, 능력별 검색 계층, 단일 모델
> 관문이 그 세 기둥이다.

## 핵심 메시지 (MECE한 근거 축)
1. **전체 구조** — 에이전트 루프를 중심으로 사내 시스템 통합(게이트웨이),
   검색, 모델 호출이 명확히 분리된다 (kori-arch-v7.6 §1·§2)
2. **결정론적 보안** — 권한 판정과 산출물 검증은 LLM이 아닌 결정론적 규칙
   (C14)이 집행한다. ACL pre-filter가 쿼리 시점에 걸린다 (D4·D16)
3. **검색 품질** — Lexical/Semantic/Quantitative 능력별 리트리버 + RRF 융합,
   정형 데이터는 별도 슬롯으로 출처까지 동봉 (D1·D2·D11)
4. **운영 유연성** — 모든 모델 호출은 Model Gateway 단일 관문, 온프렘/외부
   API 선택 배포 (D7·D17)
5. **응답 속도** — 등록 시 사전 요약·캐싱(Ingestion Pipeline)으로 런타임
   부담을 배치로 이전 (D5·D8)

## Horizontal logic (슬라이드 배열 — 7장)

| # | slug | action title | 시각 자료 |
|---|---|---|---|
| 1 | 01-hero | KORI Answers — 엔터프라이즈 AI 답변 아키텍처 | 히어로 3D 렌더 (ComfyUI, 레이블 없음) |
| 2 | 02-architecture | 전체 아키텍처 — 에이전트 루프가 검색·모델·보안을 오케스트레이션한다 | **메인 2.5D 아이소메트릭** (C1~C17, R1~R21, R15 제외, swappable 배지 + 범례) |
| 3 | 03-security | 환각이 보안을 뚫지 못한다 — 결정론적 보안 레이어가 권한 판정과 산출물 검증을 집행한다 | C14 중심 다이어그램 (R17·R18·R19) |
| 4 | 04-retrieval | 질문의 성격에 맞는 검색 — 능력별 리트리버와 별도 정형 슬롯이 답의 근거를 만든다 | C7 내부 (툴 5종, RRF, 컨텍스트 슬롯) |
| 5 | 05-gateway | 모델은 교체 가능한 부품 — 단일 관문이 온프렘/외부 API를 라우팅한다 | C16 중심 (R6~R9) |
| 6 | 06-ingestion | 응답 속도는 등록 시점에 결정된다 — 사전 요약·캐싱 파이프라인 | C15 내부 전개 (별도 장, v7.6 §2 적재) |

- 3~6장은 2장(메인)의 존을 확대하는 zoom-in 구조 — 수평 논리 일관.
