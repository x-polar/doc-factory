# 원본에 가깝게 재현하는 법 (Fidelity Guide)

기존 문서(회사소개서 등)의 특정 슬라이드를 **그대로 살리고 싶을 때** 어떻게 지시하면
되는지 정리한다. 핵심은 **분위기가 아니라 구조를 지시하는 것**이다.

## 1. 원본 페이지를 지목한다

> "회사소개서 3p(Workforce Composition) 구성 그대로."

원본이 `brands/<brand>/refs/`에 있으면 에이전트가 **직접 열어 실측**한다
(레이아웃·색·비율·폰트). "느낌 비슷하게"보다 훨씬 정확하다.

## 2. 구조를 문장으로 쓴다 (분위기 X)

| 나쁜 지시 | 좋은 지시 |
|-----------|-----------|
| "원본처럼 세련되게" | "왼쪽에 파이 차트, 그걸 점선 원이 감싸고, 오른쪽엔 로고 리스트" |
| "인물 소개 슬라이드" | "원형 사진 왼쪽, 이름·학위·실적 리스트 오른쪽, 두 명 세로로" |

## 3. 표현 가능한지 먼저 확인한다 ★

**`reference/layout-catalog.md`에 없는 표현은 지시만으로 나오지 않는다.**
없으면 레이아웃을 먼저 추가해야 한다. 실제로 회사소개서 3p·4p를 재현할 때
아래가 없어서 새로 만들었다:

| 원본이 쓴 것 | 당시 상태 | 조치 |
|---|---|---|
| 파이 차트 | 막대만 있었음 | `pie` 레이아웃 추가 |
| 점선 원 2개(정규직·계약직) | 없음 | `pie.satellite` |
| 계열사 로고 5개 | 자산 없음 | 원본 pptx에서 투명 PNG로 추출 |
| 원형 인물 사진·세로 스택 | 사각·가로만 | `team`에 `shape`/`orient` 옵션 |

그러니 요청 시 **"이거 지금 표현 가능한가?"를 먼저 물어보면** 헛수고가 없다.

## 4. 자산은 원본에서 꺼내 쓴다

원본 pptx는 자산 창고다. 실제로 꺼내 쓴 것:
- 풀블리드 배경 4장(5K PNG → 305dpi JPEG)
- 제품 스크린샷 6장(MARU·Kori Code·AMOS·KT·HS Code·인물)
- 고객사 로고월 25개(휘도→알파로 배경 제거)
- 계열사 로고 5개(**원본 알파 채널 우선** — 휘도로 재계산하면 검은 로고가 뒤집힌다)

## 5. 색도 추측하지 말고 원본에서 뽑는다

파이 차트 색은 브랜드 기본 팔레트(오렌지 계열)가 아니라 **원본 덱이 실제로 쓴
로즈/탄/슬레이트**였다. `theme.yaml`의 `colors.series`를 그 값으로 교체했다.
"브랜드 색이니까 오렌지"라고 가정했으면 원본과 달라졌을 것이다.
